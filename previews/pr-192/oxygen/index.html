What differs between the two editions. They are built from the same DITA source; the student edition is the filtered pass. It drops the instructor-only analysis sheet from each gram, drops the matching entry from the gram's jump-link bar, and hides the search box.

On a gram page. Each spectrogram is an interactive viewer — hover for a cursor readout in time and frequency. The jump links in the toolbar move between the stages of a gram (Lofar 1, Lofar 2, …).

Scope. This is a sample build for review, not the delivered publication, and the vessel names in it are placeholders.
